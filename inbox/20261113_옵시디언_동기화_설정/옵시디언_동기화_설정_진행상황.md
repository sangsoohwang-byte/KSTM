# 옵시디언 동기화 설정 — 진행 상황

- 작성일: 2026-11-13 / 갱신: 2026-11-19
- 상태: **구글 드라이브 경로 시험 중** (PC 옵시디언에 이 노트가 보이면 성공)

## 목적

옵시디언 볼트를 Claude 작업의 보조 기억 저장소로 쓴다.
휴대폰·회사 메인 PC·노트북 어디서 지시해도 문서가 한 곳에 모이고 엉키지 않게 한다.

## 11/19 확인 결과 (PC 폴더 화면 + 구글 드라이브 조회)

- PC 볼트 위치는 `C:\Users\User\경성시험기`가 맞다.
- 이 폴더는 **구글 드라이브로 동기화**되고 있다. (`.tmp.drivedownload`, `.tmp.driveupload` 폴더와 초록색 동기화 표시)
- 구글 드라이브에 같은 `경성시험기` 폴더가 있고, 그 안에 `00_INBOX`, `01_영업`, `02_입찰`, `Claude outputs` 등이 그대로 있다.
- 볼트 안에 GitHub 저장소의 `inbox` 폴더는 없다. 즉 **볼트는 GitHub와 연결되어 있지 않다.**
- 그래서 지금까지 GitHub에만 저장한 문서 3건은 PC 옵시디언에 나타나지 않았다.

## 결론: 저장 경로를 구글 드라이브로 바꾼다

| 구분 | 방식 |
|---|---|
| 옵시디언에 보여야 하는 문서 | Claude가 구글 드라이브의 `경성시험기/00_INBOX`에 직접 저장 → PC로 자동 동기화 |
| 코드·스킬·3D 모델 등 작업 파일 | GitHub 저장소(`kstm`)에 저장 (지금처럼) |

- 볼트 폴더 안에 Git(Obsidian Git)을 추가로 넣지 않는다. 구글 드라이브와 Git을 같은 폴더에 겹쳐 쓰면 파일이 깨지거나 중복될 수 있다.
- 구글 드라이브가 원본 하나이므로 기기 간 엉킴 걱정이 줄어든다.

## 시험

- 이 노트를 구글 드라이브 `경성시험기/00_INBOX`에 올렸다. (파일명: `20261119_옵시디언_동기화_설정_진행상황.md`)
- PC 옵시디언의 `00_INBOX`에 이 노트가 보이면 경로가 정상이다.
- 보이지 않으면 구글 드라이브 데스크톱 앱의 동기화 방향(웹 → PC)을 점검한다.
