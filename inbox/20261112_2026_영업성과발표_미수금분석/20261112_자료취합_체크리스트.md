## C. 자료별 꼭 있어야 할 항목
### 1. 프로젝트 (ERP)
프로젝트번호 / 거래처명 / 사업자등록번호 / 품목(제품군) / 계약금액(부가세 별도 여부) / 수주일 / 납기 / 납품일 / 검수 완료일 / 영업 담당자 / 진행 상태 / 국내·해외

### 2. AS (ERP)
접수번호 / 거래처명 / 사업자등록번호 / 접수일 / 완료일 / 유상·무상 / 청구금액 / AS 담당자 / 관련 프로젝트번호

### 3. 매출 세금계산서 (홈택스)
작성일자 / 승인번호 / 발급일자 / 공급받는자 사업자등록번호 / 상호 / 공급가액 / 세액 / 합계 / 품목명 / 비고 / 분류(일반·수정)
- 경로: 홈택스 → 전자(세금)계산서 → 목록조회 → 매출 → 엑셀 내려받기
- 조회 기간 제한이 있으면 분기별로 나눠 받기
- 수정세금계산서(마이너스 발행) 포함
- 해외 수출분은 세금계산서가 없음 → 수출 건 목록(인보이스 금액, 입금일) 별도 필요

### 4. 입금 내역
입금일 / 입금자명 / 금액 / (가능하면) 거래처명·프로젝트번호
- 통장 내역이면 출금·급여 등은 지우고 거래처 입금 건만
- 어음·전자채권으로 받은 경우 만기일도 표시

### 5. 이월 미수금
거래처명 / 사업자등록번호 / 2026-01-01 미수 잔액 / 최초 발생일 / 담당자

### 6. 결제 조건
프로젝트번호 / 계약금 % · 중도금 % · 잔금 % / 각 지급 기한(예: 검수 후 30일) / 하자보증 유보금 유무

### 7. 미수 사유 (1차 대조 후 담당자 작성)
사유 분류: 검수 지연 / 하자·보완 중 / 고객 자금 사정 / 고객 내부 결재 지연 / 금액 분쟁 / 청구 누락 / 기타
회수 계획: 조치 내용 / 예상 입금일 / 필요한 지원

## D. 자료가 없을 때 대안
| 없는 자료 | 대안 |
|---|---|
| ERP 엑셀 내려받기 불가 | 화면 캡처 또는 인쇄 PDF |
| 사업자등록번호 없음 | 9번 거래처 목록으로 상호 매칭 |
| 입금 내역 받기 어려움 | 회계의 거래처별 미수금 현황표만 받아도 잔액 분석 가능 (경과 일수는 제한적) |
| 결제 조건 정리 안 됨 | 금액 상위 20건만 우선 입력 |
