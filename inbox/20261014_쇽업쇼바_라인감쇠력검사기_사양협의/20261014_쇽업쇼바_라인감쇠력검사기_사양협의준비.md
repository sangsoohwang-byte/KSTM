# 쇽업쇼바 라인 감쇠력 검사기 – 사양 협의 준비

날짜: 2026-10-14
태그: #영업 #사양협의 #쇽업쇼바 #감쇠력 #EOL

---

## 1. 장비 개요 (한 줄 이해)
쇽업쇼바를 위아래로 일정 속도로 움직이며 **"얼마나 버티는 힘(감쇠력)이 나오는지"**를 생산라인 끝에서 전수 검사하는 장비 (EOL: End-of-Line 검사기).

## 2. 고객에게 반드시 확인할 항목

### ① 제품(시료) 정보
- [ ] 제품 종류: 트윈튜브 / 모노튜브 / 스트럿 / **전자제어(CDC·ECS, 솔레노이드 밸브)** 여부
- [ ] 치수 범위: 최소·최대 길이, 스트로크, 몸통 직경
- [ ] 장착 방식: 아이(Eye) / 스터드(Stud) / 브래킷 → 지그 종류·수량 결정
- [ ] 모델 수, 모델 교체(체인지오버) 빈도·허용 시간

### ② 시험 조건 (가장 중요)
- [ ] 최대 하중 (예: ±10~20 kN 수준인지)
- [ ] 시험 속도 포인트 (예: 0.05 / 0.1 / 0.3 / 0.6 / 1.0 m/s)
- [ ] 가진 스트로크 (예: ±25 / ±50 mm)
- [ ] 가진 방식 요구: **크랭크식(기계식)** / **전동 서보(리니어모터)** / 유압 서보
- [ ] 측정 항목: 신장(Rebound)·압축(Compression) 감쇠력, **가스반력**, 마찰력, 길이, 이음(노이즈) 등
- [ ] CDC 제품이면 전류 조건(예: 0~1.6 A 단계별) 측정 필요 여부
- [ ] 온도 보정 필요 여부 (오일 온도에 따라 감쇠력 변함)

### ③ 생산성
- [ ] **사이클 타임(택트)**: 1개당 몇 초 이내? (라인 장비 핵심)
- [ ] 스테이션 수 (1대로 충분한지, 2스테이션 병렬인지)
- [ ] 투입/배출: 작업자 수동 / 로봇 / 컨베이어 연동

### ④ 정밀도·품질
- [ ] 하중 정확도 (예: ±0.5% 이내, ISO 7500-1 Class 0.5 등)
- [ ] **Gauge R&R** 요구값 (보통 10% 이하) – 고객 품질팀이 반드시 따짐
- [ ] 마스터 시료(기준품) 검증 방법

### ⑤ 데이터·연동
- [ ] 바코드/DMC 리딩, OK/NG 판정·마킹·분류
- [ ] MES/PLC 연동 방식 (PLC 기종, 통신 프로토콜)
- [ ] 데이터 저장 기간·형식 (CSV, DB), 그래프 출력

### ⑥ 설치·안전
- [ ] 설치 공간(풋프린트), 높이 제한
- [ ] 전원(전압/용량), 에어 공급
- [ ] 안전: 라이트커튼, 안전 도어, **CE 인증 필요 여부(수출 시)**
- [ ] 소음 기준

### ⑦ 상업 조건
- [ ] 납기, FAT(출하 전 검수)/SAT(현장 검수) 조건
- [ ] 보증기간, 교육, 예비품(Spare parts)
- [ ] 적용 규격: 고객사 사내 규격 / JASO C 602 / 기타 (※ 확인 필요)

## 4. 협의 시 팁
- 첫 미팅은 **②시험조건 + ③사이클타임** 확정이 최우선 → 가진 방식·가격이 여기서 결정됨
- "기존 장비(타사) 사양서나 시험 성적서"를 요청하면 요구 수준 파악이 빠름
- 미정 항목은 "협의 후 확정(TBD)"으로 남기고 회의록에 담당자·기한 기록
