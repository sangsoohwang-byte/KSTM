# 구글 드라이브 정리 계획

## 1. 현재 상태

- **내 드라이브 최상위**: 파일·폴더 **551개**가 폴더 없이 흩어져 있다. 가장 오래된 것은 2010년 파일이다.
- **경성시험기 폴더**(옵시디언 볼트): 번호 폴더 체계(00~08)는 갖춰져 있으나 중복 폴더와 잡파일이 있다.

## 2. 정리 원칙

1. **삭제는 하지 않는다.** 지울 만한 것은 "휴지통 후보"로 표시만 하고, 사장님(사용자) 확인 후 처리한다.
2. **2023년 이후 파일** → 경성시험기의 해당 번호 폴더로 옮긴다.
3. **2022년 이전 파일** → `04_Archive/2022이전/<분야>`로 옮긴다. (분야는 유지되므로 나중에 찾기 쉽다)
4. **개인 파일** → 최상위에 `99_개인` 폴더를 새로 만들어 옮긴다. (옵시디언에 안 보임)
5. **앱이 쓰는 폴더는 그대로 둔다**: Colab Notebooks, Gemini Gems, Opal, Google AI Studio, GoodNotes, Hearlog, 구글 사이트·설문·스크립트.
6. 이동은 파일 ID 기준으로 하므로 **구글 문서의 공유 링크는 그대로 유지**된다.

### 중복 파일 (45건)
제목과 형식이 같은 파일이 2개 이상인 경우다. 예: `회사소개서_경성시험기` 2개, `F00000_구동부 UNIT.dwg` 3개, `trw pt1004의 번역된 사본` 여러 개.
