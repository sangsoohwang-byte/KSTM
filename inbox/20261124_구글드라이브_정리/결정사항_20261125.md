# 구글 드라이브 정리 - 결정 사항 (11/25)

## `경성시험기` 폴더가 두 개
| 구분 | 웹 위치 | PC 위치 |
|---|---|---|
| 옵시디언 볼트 (이번 정리 대상) | [컴퓨터] → [내 컴퓨터] → 경성시험기 | `C:\Users\User\경성시험기` |
| 별개의 작업 폴더 | [내 드라이브] → 경성시험기 | `내 드라이브\경성시험기` |

- 작업 폴더 내용: 카탈로그 개정(웹페이지 코드 포함), KCL 인발시험지그(3D·STEP·코드), 입찰, 영업, 업무절차매뉴얼 양식
- **결정: 작업 폴더는 그대로 둔다.** 진행 중인 작업(11/18~23)과 코드가 있어 옮기지 않음.
- 구분 내용을 작업 규칙(`CLAUDE.md`)에 기록함 → 다른 기기의 Claude 세션도 같은 기준으로 작업

- `드라이브정리_휴지통스크립트.txt` 실행 대기 중
