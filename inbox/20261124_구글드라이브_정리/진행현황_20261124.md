## 스크립트 실행 방법 (PC에서 5분)
1. 이 폴더의 `드라이브정리_이동스크립트.gs`를 열어 내용 전체 복사
2. https://script.google.com 접속 → **새 프로젝트**
3. 기존 내용 지우고 붙여넣기 → 저장(Ctrl+S)
4. 위쪽 함수 선택이 `runMoves`인지 확인 → **실행**
5. 권한 승인 창: 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
   (본인이 만든 스크립트라 뜨는 일반 경고)
6. 아래 실행 로그에 `이동 N / 건너뜀 N / 실패 N` 확인
   - "시간 제한" 문구가 나오면 **실행을 한 번 더** 누른다 (이미 옮긴 건 건너뜀)
