
- `제어부` — 연노랑
- `시운전` — 연보라

## 생성 파일 구조

### 시트 1 : 견적서
- 見積書 표지 형식
- 합계금액 = 견적BOM 판매 총합계 (수식 자동 연결)
- 납기, 담당자, 지불 조건 포함

### 시트 2 : 견적BOM (12열 구조)
| 열 | 내용 | 비고 |
|----|------|------|
| A | No | 입력 |
| B | 분류 | 입력 |
| C | 대분류 | 입력 |
| D | 품명/항목 | 입력 |
| E | 규격/사양 | 입력 |
| F | 수량 | 입력 |
| G | 단위 | 입력 |
| H | 판매단가(원) | 수식: 부품·자재 =J*1.4, 인건비(기구부·제어부·시운전) =J |
| I | 판매금액(원) | 수식 =F*H |
| **J** | **사입단가(원)** | **입력값 (파란색)** |
| K | 사입금액(원) | 수식 =F*J |
| L | 비고 | 입력 |

- 분류 변경 시 소계 행 자동 삽입 (`=SUM(...)`)
- 하단 총합계 (`=SUM(소계셀들)`)
- **사입단가(J열, 파란색)만 수정하면 전체 자동 갱신**

## 인건비 기준 (사입단가)
| 구분 | 단가/일 | 적용 항목 |
|------|--------|---------|
| 설계 | 500,000원 | 기계설계, 제어설계, SW개발 |
| 가공·조립 | 400,000원 | 가공, 도장, 배선, 조립 |
| 시운전·납품 | 450,000원 | 시운전, 설치, 교육, 문서 |

## Claude 작업 절차

1. **고객 요구서(SOW/RFQ) 확인** — 사양, 범위, 제외 항목 파악
2. **BOM 항목 구성** — 분류별 품목 리스트 작성
3. **JSON 데이터 생성** — 사입단가 기준으로 작성 (`사입단가` 키 사용)
4. **스크립트 실행**
```bash
python "C:\Users\User\경성시험기\generate_bom.py" \
  --json <json파일경로> --out <출력경로.xlsx>
```
5. **파일 저장** — `C:\Users\User\경성시험기\01_영업\견적\<고객사>\` 하위

## 주의사항
- `사입단가` 키가 없으면 `단가` 키를 판매단가로 간주해 역산(÷1.4)
- 운송비 등 고정 비용은 인건비율 대신 실제 비용으로 입력
- 칠러·유압블록·리모컨·유압실린더 등 추가 사양은 JSON에 추가 후 재실행
